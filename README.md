# Brayan Beef — Açougue (projeto fictício)

> **Aviso:** site 100% fictício criado para portfólio. Nome, endereço
> (Av. Fictícia, 333 — Porto Fictício/EX), telefone `(00) 90000-0009`,
> WhatsApp, preços e mapas são inventados. Nenhum dado é real e não
> representa nenhuma empresa.

🌐 **Demo no ar:** https://brayanbeef.vercel.app

Site de açougue fictício (TanStack Start): vitrine de cortes, produtos,
sobre, contato com mapa + painel admin. Os dados vêm dos JSONs em `data/`
(ou de CMS via `GITHUB_TOKEN`, se configurado).

## Stack

- TanStack Start (Vite + Nitro) + React + Tailwind + shadcn/ui
- SEO: JSON-LD, sitemap, robots

## Rodar local

```bash
bun install
bun run dev
```

## Deploy

Hospedado na Vercel. Push na branch principal = redeploy.
